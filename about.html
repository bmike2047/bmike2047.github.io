About this portfolio

Software development, electronics and the physics in between.

I'm Mihai Buleandra. I work with Java and enjoy exploring how software interacts with physical systems—from Raspberry Pi hardware to electromagnetic fields and radio antennas.

My engineering interests

Java software development, Spring applications, concurrent and event-driven code, automated testing and integration systems. Beyond software, I study electronics, RF propagation, antenna behaviour and electromagnetic theory.

Feynman's lectures have been one of my inspirations for trying to understand systems from fundamental principles rather than memorised formulas.

What you'll find here

  • Java, Spring Boot and desktop software projects
  • Source code and project documentation on GitHub
  • Integration, concurrency and automated testing
  • Projects exploring electronics and RF engineering
